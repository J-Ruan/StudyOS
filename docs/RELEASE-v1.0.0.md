# 学序 v1.0.0

大学生个人学习控制台，简体中文、无需登录、无服务器、无收费 API。

- 完整课程表：教学周、单双周、多时段、冲突提示、停课、调课、加课。
- 关联课程的任务、子任务、重复待办、考试与复习。
- 时间戳专注计时，暂停与刷新恢复，有效学习区间统计。
- 日、周、月统计、课程投入、习惯日历与每周复盘。
- 自习时间安排，课程本地文件与链接管理。
- IndexedDB 持久化、版本迁移、含文件的 JSON 备份与事务恢复。
- 响应式界面、完整深色模式、可安装且可离线启动的 PWA。

生产文件见附件 `StudyOS-v1.0.0.zip`，部署于 `/StudyOS/` 子路径。源码和构建均不包含个人学习数据。

数据只保存在当前浏览器，请定期导出备份。后台音频受系统限制；计时会在返回应用后按真实时间结算。

发布工作流在类型检查、ESLint、单元/集成测试、生产构建和关键路径浏览器测试全部通过后才创建此 Release。
