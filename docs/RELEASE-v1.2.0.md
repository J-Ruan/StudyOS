# 学序 v1.2.0 · Android 体验升级

## 功能

- 新应用图标：深紫色书页与书签，支持 Android 自适应图标及单色主题图标。
- 手机导航改为今天、课程、任务、专注、我的；保留旧路径。首页优先显示课程、待办与快捷专注。
- 课程提供今日、连续三日和周课表；支持日期切换、滑动、教学周、临时调整及独立自习标记。
- 任务快速创建只需标题与截止时间，高级字段折叠；保留完整编辑，并支持批量完成、确认删除、长按操作与关联专注。
- Android 本地任务、考试和专注提醒；多项提前/指定时间提醒、系统权限、原生通知点击与专注控制。
- 可配置番茄循环、短/长休息、每组轮数、自动/手动进入下一阶段；以持久化时间戳结算，事务防止重复学习记录。
- 离线规则学习计划：避开课程、考试和已有安排，预览调整后确认保存；支持手动安排、改时、完成、取消和关联专注。
- 本地 CSV / XLSX 课表导入，支持标题行、字段映射、预览、去重、合并、冲突检测和事务写入。
- 主题强调色、启动页、专注和通知偏好；备份通过 Android 系统保存界面，展示最近导出时间。

## 数据和升级

包名保持 `com.jruan.studyos`，versionName `1.2.0`，versionCode `120`，Android 7.0 及以上。

数据库 `studyos` 采用正式 v3 升级，保留 v1 → v2 逻辑及所有历史实体；旧任务内的自习安排以稳定编号迁入 plans。JSON v3 包含新计划、设置与资料，继续支持 v1/v2 备份的合并和覆盖恢复；导入先校验，再原子写入，重复导入不重复累计。

升级前请在旧版导出 JSON。旧 v1.1.0 的 Debug 签名可能与正式签名不同，Android 无法直接覆盖时，必须先备份再卸载、安装和恢复。卸载会删除本地数据。Web 与 APK 数据独立，通过 JSON 迁移，不自动同步。

## 签名发布条件

仅在正式签名 Secrets 完整、签名校验和全部 CI 检查通过后发布 `StudyOS-v1.2.0-android.apk`；附件同时包含 Web ZIP 和 `SHA256SUMS.txt`。开发/测试 Debug APK 不会作为本次正式 Release 的替代品。

## 平台边界

- 通知需要用户授权；精确提醒是单独的系统权限，未授权时使用普通调度，可能延迟。省电、厂商策略及强制停止会影响通知，不能保证所有设备绝对准时。
- 专注状态通知显示阶段、结束时间及打开应用执行的暂停/继续/结束操作；没有后台常驻服务。锁屏内容是否显示由系统隐私设置决定，不提供假后台按钮。
- 自动循环按一组固定轮数运行，长休息结束后停止；应用恢复时按相同时间轴补齐本组已经完成的阶段，不无限推算学习时长。
- Excel 导入处理第一个工作表；复杂排版请选正确标题行并手动映射，或使用提供的 CSV 模板。最多 5 MB、2000 行、100 列。
- 真实手机和厂商省电策略仍需设备验证；模拟器与浏览器结果分别记录于 Android 验证文档。
