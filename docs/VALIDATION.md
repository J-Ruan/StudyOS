## 远端运行器

首次 GitHub Actions 运行在已迁移到 Ubuntu 26 的 `ubuntu-latest` 上，浏览器系统依赖安装步骤失败。工作流已固定为 受支持的 `ubuntu-24.04`；CI 使用运行器预装的 Chrome，并输出 GitHub 失败注释。更新测试先确认数据库保存完成再刷新；保留全部检查和发布门槛。

## 范围限制

- 已在 Linux Chromium 中实际验证响应式尺寸；未把模拟宽度称为真实 Android、Windows 或平板硬件测试。
- 浏览器/系统休眠时不能保证及时响铃。返回页面后按绝对时间戳补结算，学习时长不依赖计时器回调次数。
- 数据按浏览器和站点隔离，不自动同步。清理站点数据或浏览器回收存储可能造成丢失；应定期导出含资料的备份。
- 自习规划将考试按 2 小时占用计算。单文件上限 20 MB，备份导入上限 150 MB。
- 本地测试和构建不代表 GitHub 服务已经发布。远端 CI、Release 与 Pages 状态以 GitHub 实际结果为准。
